# Welcome to Financial-Analytics Docs

This project is a collection of Python scripts designed to automate and simplify complex financial data analysis. It provides a modular set of tools for fetching key metrics, running custom screeners, and performing specialized calculations.

### Automated Data Retrieval

A suite of functions to quickly fetch essential financial metrics and keep your analysis current with up-to-date data.

- [API Reference](api_reference.md)

### Powerful Stock Screeners

Tools to run custom screeners to identify stocks that meet your specific investment criteria.

- [Screener Guides](screener_guides.md)

### Specialized Bond Analytics

A dedicated suite of tools for in-depth bond market analysis, including bond returns, yield-to-worst (YTW), and auction calendars.

- [Bond Analytics](bond_analytics.md)

---

### Getting Started

To get started, simply navigate the sections in the left-hand sidebar:

* The **API Reference** provides a detailed overview of every function, its parameters, and its purpose.
* The **Screener Guides** offer explanations on how to use the high-level screener scripts.
* The **Bond Analytics** section is for a deep-dive into the bond market-specific tools.
